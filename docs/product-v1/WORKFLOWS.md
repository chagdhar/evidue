# Product Workflows

## New vendor

Create contract -> create/link vendor engagement -> build agreement bundle -> compile AIR -> assurance -> human approval.

## Monthly invoice

Upload invoice -> attach to engagement -> ingest evidence -> match identities -> persist verification plan -> reconcile -> create review cases -> refresh settlement statement.

## Exception review

Open review case -> inspect machine reason/evidence -> record payable/disputed/escalated decision -> refresh statement. Determination is unchanged.

## Payment approval

Open statement -> verify hashes/authority -> ensure open review amount is zero -> approve -> freeze approved amount/hash.

## Vendor dispute

Approved statement -> create case -> include disputed machine determinations and review-disputed items -> ready -> sent -> vendor responded -> under review -> accepted/partially accepted/rejected -> closed.
