# Mobbin Reference Board for Evidue

Mobbin should be used as a pattern library, not copied as a visual theme.
Search for shipped web products that solve the same interaction problem.

## Recommended searches

### Financial decision hierarchy

Search:

- invoice approval dashboard
- spend management transaction detail
- payment reconciliation
- financial close review
- expense audit

Look for:

- one dominant financial number
- submitted versus approved comparisons
- compact supporting metrics
- review actions adjacent to the decision

### Findings and exception review

Search:

- risk findings table
- transaction exceptions
- fraud review queue
- compliance findings
- dispute management

Look for:

- filter toolbars
- compact status labels
- row-level evidence access
- amount and reason alignment
- persistent review context

### Contract and rule review

Search:

- policy editor
- contract review
- approval workflow
- version history
- rule builder

Look for:

- document-plus-structure split views
- version comparison
- clear approved/pending state
- restrained raw JSON disclosure

### Evidence inspection

Search:

- activity log drawer
- transaction detail drawer
- audit trail
- event timeline
- source record inspector

Look for:

- right-side drawers
- chronological event timelines
- source and authority labels
- provenance metadata
- copyable IDs and timestamps

## Patterns to avoid

- consumer banking balance cards
- crypto dashboards
- AI gradients and sparkle icons
- generic analytics chart walls
- glassmorphism
- large empty hero sections
- card grids where a table is required

## Implementation note

Mobbin provides a large library of real shipped mobile and web references and
supports MCP access for compatible paid plans. When Mobbin MCP is connected to
Codex, ask for references by interaction pattern rather than by visual style.
